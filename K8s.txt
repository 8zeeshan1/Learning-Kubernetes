Install go language in our pc as k8s built using the go lang, but that doesn't actually needed to use the k8s it's just for the learning purpose.
we will be needing a package manage choco.
We have to ensure that kubectl is installed in the system as it is the cli command of k8s.
then install the kind. it helps in running k8s with the help of the docker.

We will be using kind to install k8s in our local system.
In this installation the docker containers will be acting as the separate nodes.
So we would be needing the docker engine to be continuously running.
then we would be needing the chocolaty package manager installed in the system.

with the help of -> choco install kind --We will be intalling the kind.
then we will make the cluster using kind-> kind create cluster --image <the version required> --name <name of the cluster>
kubectl cluster-info --context kind-<name of the cluster> ==> We can see if the control plane is running and where is it running.
